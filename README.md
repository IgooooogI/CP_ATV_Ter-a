# Site Pessoal / Portfólio — Igor Pedrosa (CP3)

Site com 5 páginas (`index`, `curriculo`, `formulario`, `multimidia`, `graficos`) feito em HTML, CSS e JavaScript.

- **Feature interativa:** formulário de contato com validação e feedback; as mensagens enviadas ficam salvas em `localStorage` e podem ser removidas. Também há alternância de tema claro/escuro, que lembra a escolha.
- **Código:** `css/estilos.css` e `js/scripts.js`.
- **Publicação:** GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
